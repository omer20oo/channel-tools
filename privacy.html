Privacy Policy

Channel Tools uses the YouTube Data API and YouTube Analytics API only to upload and schedule videos, set thumbnails and captions, and read analytics for the owner's own YouTube channels.

  • No personal data is collected, sold or shared.
  • Access tokens are stored only on the owner's own computer and are never sent to any other server.
  • Data received from Google APIs is used only to show the owner their own channel statistics.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
